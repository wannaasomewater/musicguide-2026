# Основной сценарий (happy path)

1. Пользователь открывает веб-интерфейс (Streamlit).
2. Вводит вопрос: «Чем отличается джаз от блюза?»
3. Нажимает «Найти ответ».
4. Интерфейс показывает:
   - поле ввода вопроса;
   - блок «Найденные документы» (топ-5 фрагментов с BM25-скорами);
   - блок «Ответ LLM» с ссылками на источники.
5. Пользователь может раскрыть каждый документ.

## Альтернативные сценарии
- Вопрос не по теме → система сообщает «в корпусе нет релевантных документов».
- Пустой запрос → валидация, кнопка неактивна.
- Ошибка LLM → показываем найденные документы без генерации.

## Нефункциональные требования
- Ответ за ≤ 10 секунд на CPU (Mac M3).
- Работает локально, без обязательного внешнего API.
