# Архитектура

## Компоненты
1. **Корпус** — JSONL-файл с документами (песни, метаданные, тексты).
2. **Индексатор** — строит BM25-индекс (rank_bm25).
3. **Поисковик** — top-k фрагментов по запросу.
4. **LLM-модуль** — формирует ответ по найденному контексту.
5. **API** — FastAPI: POST /ask.
6. **Интерфейс** — Streamlit.

## Схема
Пользователь → Streamlit UI → API → BM25 → top-k → Prompt → LLM → ответ+источники → UI

## Технологии
- Python 3.11 (venv на Mac M3)
- rank_bm25
- FastAPI + uvicorn
- Streamlit
- LLM: локальная (Ollama) или внешний API (опционально)

## Папки
- app/ — код приложения
- tests/ — pytest-тесты
- benchmark/ — вопросы и метрики
