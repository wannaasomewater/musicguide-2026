# MusicGuide

RAG-помощник по музыкальной базе знаний: ищет ответы в документах через **BM25** и формирует ответ с помощью **LLM**.

## Основной сценарий

1. Пользователь вводит вопрос о музыке.
2. Система ищет релевантные фрагменты в корпусе через BM25.
3. LLM формирует ответ на основе найденного контекста.
4. Ответ сопровождается списком источников.
